# Splash4GH

Simple, polished GitHub Pages splash site with:
- A homepage with two clickable tiles
- A documentation page
- An app page

## Files
- `index.html` - splash homepage
- `docs.html` - documentation destination page
- `app.html` - app destination page
- `style.css` - shared visual style

## Publish on GitHub Pages
1. Push this folder to a GitHub repository.
2. In repository settings, open **Pages**.
3. Set source to deploy from your default branch root.
4. Save and wait for deployment.
5. Visit your `https://<username>.github.io/<repo>/` URL.

If this repo is named `<username>.github.io`, your site will be at the root domain:
`https://<username>.github.io/`
